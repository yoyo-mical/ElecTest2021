# ElecTest2026 桌面测试包 r5

本轮解决 r4 未同步已确认网页功能的问题。界面使用真实 C# 桥接，不包含公开体验站的模拟采样、模拟串口或配方执行器。

| 清单编号 | 本轮更新 |
| --- | --- |
| D-001 / D-002 | 编辑与曲线左右拖动、上方区域与配方上下拖动；键盘调整、双击恢复 |
| D-003 | 串口面板内折叠 HEX→ASCII 工具，独立转换，不触发发送 |
| D-004 / D-005 | RGB、Gray 两个独立组及应用按钮；Gray 不覆盖 RGB；只向对应 C# 操作提交该组参数，状态推送不覆盖未提交输入 |
| D-006 / D-007 | 当前曲线原始点 Sheet、当前 CSV 导出、原 Sheet 的多组数据及原导出/清空入口 |
| D-008 | 经典深蓝；保留中性灰与柔和暖白 |
| D-009 / D-010 | 共享界面源、构建和包内同步检查，新增功能浏览器回归用例 |
| D-011 / D-012 | 在 WebView2 回调返回后调度原 STA 流程，拦截重复排队、支持取消未开始请求；运行时保留主题/查看操作，锁定设备和参数修改 |

“暂停”已改为“停止”，沿用原退出标志，不提供暂停续跑。不能强行中断厂商 SDK 调用；停止在原流程的安全检查位置生效。配方、串口协议、延时与 SDK 调用顺序未改。仍只在启动时检查授权。

r3 的字符串初始化兼容性修复、干净 ET 图标及 r4 的默认 JSON 保留。

## 已验证与限制

浏览器三主题、三尺寸及功能交互、26 项混淆后 C# 后端检查、虚拟串口精确字节、CSV 原始点内容、授权/路径/完整性检查通过。截图是受控桥接测试，不是 Windows 实机或仪器截图。

Windows/WebView2 实际停止响应、原保存/清空对话框、剪贴板和仪器联调仍待用户本机确认。本环境不具备 Windows 或物理仪器。

## 本机重点复测

1. 完整解压到新文件夹，配置根目录 settings.json，启动授权。
2. 拖动两个内部边界；切换三种主题；打开 HEX→ASCII，测试 CRLF。
3. 连接设备、选择支持图案，按 RGB=128/0/0 → Gray=255 → RGB 应用，核对设备输出与输入框独立保持。
4. 运行配方，在原“运行”提示框关闭后，测试主题切换、曲线/Sheet 查看及停止；检查停止后不会继续后续步骤，可再次启动。
5. 核对原 Sheet 与当前曲线点，分别导出，检查真实值及组列；清空需单独确认原操作。

遇到启动或执行异常，提供 `%LOCALAPPDATA%\ElecTest2026\startup.log` 和 `launcher.log`，并注明执行的配方及所处步骤。
