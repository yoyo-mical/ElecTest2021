# ElecTest2026 桌面测试包 r6

本轮将已评审 HTML 版本7的待更新项 D-013–D-022 接入真实 C# 桌面后端。生产包不包含体验站模拟串口、模拟采样或模拟配方执行器。

| 范围 | 本轮更新 |
| --- | --- |
| 串口 | 接收默认 ASCII，HEX 独立切换；原始字节缓存、复制、清接收；手动 HEX/ASCII 发送及结尾选择，非法内容整条拒绝。最近64KiB接收缓存溢出有明确提示 |
| 布局 | UART/CA410 上下 split；保留另两处 split；六面板展开布局；CA410 按真实连接状态变绿 |
| 操作归属 | 去除顶部操作条；运行操作归 Control，脚本下发归 ARMCode，导出归测量结果 |
| 测量结果 | 当前曲线、当前原始点 Sheet、曲线+Sheet、Chart2 多组独立图卡及全部测量组；当前 CSV 与全部测量组 CSV 分开 |
| 脚本 | ARMCode Sheet 改为只读脚本指令表，保留原文、空行、注释及行号，可定位 Code |
| 运行与退出 | 增加安全边界暂停/继续；保留停止与单步；删除旧运行调试弹窗；关闭窗口、Alt+F4 或退出按钮先原生确认，默认否 |

暂停、停止及确认退出均等待当前设备调用/原延时安全返回，在命令或采样边界处理，不能强行中断 SDK；暂停时间自然延长整体测试用时。取消退出不主动停止测试或断开连接。

RGB、Gray 保持独立输入和实际发送：RGB=128/0/0 → Gray=255 → RGB 应用，依次发送 128/0/0、255/255/255、128/0/0，不覆盖另一组编辑值。保留原协议报文、SDK 调用顺序和延时表达式。

便携根目录仍只有 ElecTest2026.exe、settings.json、程序及运行组件；默认 licensePath 为空。仅启动校验授权；保留 r3 字符串初始化兼容修复和干净 ET 图标。未提供发布者数字签名。

## 已验证与限制

- 正式桌面 HTML 资产通过 Chromium 交互回归：三处 split、六面板展开、三主题/三尺寸、独立串口格式、RGB/Gray、脚本表、测量多视图、暂停/继续/停止桥接及退出入口，无 JS 错误。
- 40项混淆后 C# 后端检查通过；虚拟串口精确核对原图案、RGB/Gray、手动 HEX 与 ASCII+CRLF 字节；原协议/延时/SDK调用顺序检查通过。
- 接收、曲线和表格来自真实后端；浏览器测试响应仅存在于测试中。自动检查不能代替 Windows/WebView2 和物理设备验收，本环境没有这些条件。

## 本机重点复测

1. 解压到新目录，保留原包备份；配置根目录 settings.json 并授权启动。需要 .NET Framework4.8、WebView2 Runtime、厂商驱动及原厂依赖的x86运行库。
2. 三处拖动、六面板展开/还原，运行中切主题和查看结果；串口接收切换、复制 CR/LF，检查手动发送结尾，确认不会影响配方协议。
3. 用已验证安全的配方检查暂停后不再执行下一安全边界步骤、继续保持位置、停止不重复启动；设备阻塞时仍需等待返回。
4. 测多个项目，检查独立图卡、同组曲线与表格数值、全部组原始配对列及两个 CSV 导出范围。
5. 修改脚本后核对指令表与定位；连接CA410检查按钮色与失败状态；RGB/Gray实际输出依次检查。
6. 空闲和运行中分别关闭窗口：默认取消/否，取消保持状态；确认后安全退出，不强杀设备线程。

异常时提供 `%LOCALAPPDATA%\ElecTest2026\startup.log`、`launcher.log` 和对应配方/步骤；可运行组件目录的 START-DIAGNOSTIC.cmd。
