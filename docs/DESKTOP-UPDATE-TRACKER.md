## 使用规则

- 后续确认需更新桌面版的内容，先在此表新增一行，沿用递增编号。
- 状态使用：待更新、进行中、待验证、已完成、暂缓。已有代码但缺实际验证的项目标为“待验证”。
- 只有实现并通过相应验收后才标“已完成”；发布后填写实际包名。浏览器验证、Windows 启动和硬件验证分别记录，不能相互替代。
- 用户尚未确认的方案另行注明，不作为已批准需求实施。Chart2 历史对比目前仍待确认，不计入已确认更新项。
- 保持启动时检查授权的约定；未经确认不改变串口报文、CA410 SDK 调用、执行顺序、延时或采样时序。

## 当前已知发布问题

- r2 的启动异常日志指向混淆器生成的字符串初始化代码；r3 已关闭字符串隐藏并重新打包，r4 沿用该修复。Windows 实际启动修复效果仍需本机确认，不能据构建通过认定问题已解决。
- r4 的图标和默认 `settings.json` 已更新，但并未包含本表所列网页功能同步；后续不能将这些功能描述为 r4 已具备。
