## 使用规则

- 后续确认需更新桌面版的内容，先在此表新增一行，沿用递增编号。
- 状态使用：待更新、进行中、待验证、已完成、暂缓。已有代码但缺实际验证的项目标为“待验证”。
- 只有实现并通过相应验收后才标“已完成”；发布后填写实际包名。浏览器验证、Windows 启动和硬件验证分别记录，不能相互替代。
- 用户尚未确认的方案另行注明，不作为已批准需求实施。Chart2 用途现已由用户指定为多测试结果图卡总览（D-019）；旧的叠加历史对比提案不再采用。
- 保持启动时检查授权的约定；未经确认不改变串口报文、CA410 SDK 调用、执行顺序、延时或采样时序。

## r6 实现与验证补充（优先于上表历史情况）
