## 安装使用与边界

完整解压到新目录后启动根目录ElecTest2026.exe；可从旧包复制settings.json的授权路径配置。需要原厂驱动、.NET Framework 4.8、VC++ x86依赖及x86 WebView2 Runtime；本ZIP不捆绑WebView2。手动放置固定运行时仍使用“程序及运行组件/WebView2Runtime/msedgewebview2.exe”结构。

新分组及精度规则作用于新采集，无法恢复旧数据已舍弃的小数，也不猜测拆分历史混组文件。未导出或执行Save前，结果仍在本次进程内存。理论刷新率不是仪器实测；只捕获到部分开机信息时不补造缺失字段。

本包沿用此前未签名便携测试包形式，不提供发布者签名。自动回归、真实厂商SDK编译和包结构检查不代替Windows物理设备验收：开机捕获率、实际串口/CA410、长配方时序、2K/4K跨屏、Windows剪贴板及保存对话框仍需本机确认。
