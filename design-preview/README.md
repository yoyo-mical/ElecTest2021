## 设计依据与调整

依据 `Testplan/MainForm.cs` 中的六个 DockContent 及其 Designer 文件：UART、CA410、ARMCode、Control、DataChart、Pattern。保持左侧设备、中间脚本/图表及下方配方、右侧图案的工作关系；为一次看到六个面板，UART 和 CA410 在本设计中上下分区。这是布局提案，不是原始程序截图。

统一面板标题、工具栏、输入框和间距。操作图标全部改为同一笔画风格的内嵌 SVG，下载、导出、删除、运行、暂停、单步、上下移动、注释和格式化等含义保持独立；主要操作带文字，小图标按钮带提示和无障碍名称。测试图案仍为内容缩略图，而不是操作图标；当前用 CSS 近似重绘供设计审阅，不能用于实际光学测试。

提供屏幕分辨率和 100%/150%/200% 缩放组合。模拟逻辑空间为物理分辨率除以缩放比例，并保留至少 1200 × 860 的工作区；不足时提示滚动查看。图案库、日志、代码与表格可在自己的区域内滚动，不把内容无限缩小。左右分隔线可拖动，也可聚焦后用方向键调整。

DPI 模拟不等同于 Windows DPI 验证；后续 C# 还需统一 AutoScale 基准、布局容器、最小尺寸与 DockPanel 比例，并验证跨屏 DPI。当前 Designer 的 AutoScaleDimensions 有 6×12、7×17、11×24 等不同值，且多处使用固定坐标；MainForm 中整体 AutoSizeFormClass 调整被注释。这些是后续实现需要处理的线索，尚不是经过 Windows 运行确认的根因结论。

## 演示交互

- 打开串口、发送、连接分析仪及测量仅模拟状态，不访问串口或仪器。

- 表格选中项会更新 ITEM；新增步骤使用上方输入值。不是完整配方编辑器，不向原项目写入数据。
- 脚本可编辑、格式化、注释和清空。下载按钮仅模拟操作；图表显示固定示例。
- 数据导出为带有“示例数据”标识的 CSV；配方导出包含 `preview:true`。导入仅接受本预览的五列步骤 JSON，并校验大小与结构。
- 恢复按钮恢复初始布局、脚本、配方和设备连接状态。所有状态仅保留在当前页面，不保存用户文件。

## 第三版：扩大曲线与明亮主题

曲线面板内部重排为标题、单行页签/项目选择，以及绘图区。连线方式、缩放、图例、演示采样按钮和说明集中在“⋯”设置菜单，以覆盖层展开，不长期占用图形高度。逐点数值在选中点后以浮层显示，点击图表空白处关闭；原始点值、轴单位和交互继续保留。SVG 按实际容器尺寸重绘，避免固定宽高比在图形两侧留出大量空白；放大面板和改变分辨率也会重算布局。

主题下拉位于预览页顶部，提供清晰蓝、中性灰、柔和暖白。三者均为明亮背景；曲线与最低点颜色含义一致，测试图案颜色不随主题改变，状态仍保留文字。主要文字、坐标轴、运行按钮的对比度已逐主题验证不低于 4.5:1；这不是对全部控件的完整无障碍认证。

`theme-blue.png`、`theme-graphite.png`、`theme-warm.png` 是三种主题的实际浏览器截图。`workspace.png` 更新为当前清晰蓝版本；`workspace-chart-before.png` 保留此次压缩辅助控件之前的版本。更新后的 validate.py 同时检查绘图区容器高度占曲线面板超过 72%、三主题的关键对比度与既有演示交互。未改动原 C# 或通信逻辑。

## Pattern 缩略预览

## 本轮：原功能映射补齐与列表下方折叠预览

当前工作区已在此前改名为 `/workspace/ElecTest2026`，预览继续在原有单文件上修改，没有重做。本轮只改 design-preview；此前项目改名留下的 C# / 工程改动属于上一任务，本轮未新增修改。

- Pattern：折叠预览移到图案列表下方，默认收起，展开不打开弹窗。分辨率、RGB/Gray、分类与列表独立显示。Back 改为 0–255 数值输入，按原 Tag 的参数类型启用；RGB/Gray 的启用状态也依据原处理方法。32 个按钮一一对应原 pictureBox1–32，内嵌原资源而非近似 CSS 图案；未确认语义的图案保留原资源名。对应关系见 PATTERN-MAPPING.md。原始资源仍仅为预览，不代表设备测试输出。
- Control：ITEM 补齐源码 Load 中的 16 项；参数折叠区增加原 Patten 的 12 个预设及原字串、可编辑 Pattern 内容、DownLoad 内容、Read/Save 路径与选择文件入口。浏览器只提供文件名，完整 Windows 文件/目录路径可手动填写；不模拟拥有原生目录访问能力。
- 保留独立的步骤表演示，新增自由文本配方编辑视图（contenteditable），可编辑多行、选择、复制粘贴和保留基本富文本。JSON 导出同时保存原文和经过白名单清理的基本格式，重新导入保留文本及基本格式，不把原文强制解析成表格，也不接收任意可执行 HTML；不是原生 RTF 格式兼容实现。
- 从头运行、从当前行运行、单步是独立演示入口。文本编辑中点击/键盘定位当前行；格式刷依原 pictureBox2_Click 逐行 Trim。文本与表格各自保留，上下移、删除和 GoTo 根据所选视图操作。步骤添加在文本视图依据 Pattern、DownLoad、Read/Save 等内容追加演示行；不改变真实 ARM 命令、执行、延时和采样时序。所有运行按固定演示节拍，不执行原文命令。
- 对应源码：Pattern.Designer.cs 的 Tag/BackgroundImage/BackColor；Pattern.cs 的 pictureBox1_Click_1 和 patterncode；Control.cs 的构造器工具提示、Load、comboBox2_SelectedIndexChanged、button1_Click、pictureBox2_Click。
